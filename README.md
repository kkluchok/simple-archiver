# Simple File Archiver

Консольна утиліта мовою Rust для стиснення та розпакування файлів (формат Gzip).
Створена в межах курсової роботи з дисципліни «Системне програмування».

## Можливості

- Стиснення файлу в Gzip-архів (`.gz`).
- Розпакування Gzip-архіву.
- Потокова обробка файлів через `BufReader`, `BufWriter` та `std::io::copy`: розмір файлу не впливає на використання оперативної пам'яті.
- Обробка помилок без `unwrap()` і `panic!()`: відсутній файл, відмова в доступі, пошкоджений архів, збіг вхідного та вихідного файлів.
- Логування всіх подій у файл `archiver.log` із часовою міткою та рівнем (`INFO` / `ERROR`).
- Кросплатформність: Windows, macOS, Linux.

## Вимоги

- [Rust](https://rustup.rs) (встановлюється через `rustup`, разом із ним ставиться `cargo`).
- Windows: [Build Tools for Visual Studio](https://visualstudio.microsoft.com/visual-cpp-build-tools/) з навантаженням «Desktop development with C++».
- Linux: компілятор C (наприклад, пакет `build-essential`).
- macOS: Xcode Command Line Tools (`xcode-select --install`).
- Підключення до інтернету під час першої збірки (завантаження залежностей).

## Структура проєкту

```
simple_archiver/
├── Cargo.toml          # Залежності: flate2, chrono
├── README.md
└── src/
    ├── main.rs         # Точка входу, розбір аргументів, виклики processor і logger
    ├── processor.rs    # compress_file, decompress_file, власний тип помилки
    └── logger.rs       # Файловий логер із часовими мітками
```

## Збірка

```
cargo build
```

Оптимізована збірка:

```
cargo build --release
```

Виконуваний файл з'явиться в `target/debug/` або `target/release/`.

## Використання

```
cargo run -- compress   <вхідний_файл>  <вихідний_архів>
cargo run -- decompress <вхідний_архів> <вихідний_файл>
```

Після `--` йдуть аргументи самої програми. Скомпільований файл можна запускати напряму:

```
simple_archiver compress   <вхідний_файл>  <вихідний_архів>
simple_archiver decompress <вхідний_архів> <вихідний_файл>
```

### Приклад

```
cargo run -- compress input.txt input.txt.gz
cargo run -- decompress input.txt.gz restored.txt
```

Перевірка, що відновлений файл збігається з оригіналом:

- Windows: `fc.exe input.txt restored.txt`
- Linux / macOS: `diff input.txt restored.txt`

Створений архів сумісний зі стандартними засобами, наприклад `gunzip -c input.txt.gz` (Linux / macOS).

## Обробка помилок

Усі помилки перехоплюються в `main`, виводяться користувачу зрозумілою мовою та записуються в журнал. Програма завершується з кодом `1`.

| Ситуація | Повідомлення |
|---|---|
| Файл не існує | `файл '...' не знайдено` |
| Немає прав доступу | `відмовлено у доступі до '...'` |
| Архів пошкоджений або не є Gzip | `архів '...' пошкоджений або має невірний формат` |
| Вхід і вихід збігаються | `вхідний і вихідний файли збігаються: '...'` |
| Інша помилка вводу-виводу | `помилка вводу-виводу з файлом '...': ...` |

Якщо операція завершилась помилкою, недописаний вихідний файл автоматично видаляється. Уже наявний вихідний файл не чіпається, якщо вхідного файлу не існує.

## Журнал

Події записуються в `archiver.log` у поточній директорії (записи додаються в кінець файлу):

```
[2026-10-22 14:05:09] [INFO] Початок стиснення: 'input.txt' -> 'input.txt.gz'
[2026-10-22 14:05:09] [INFO] Стиснення завершено: 1024 Б -> 180 Б ('input.txt.gz')
[2026-10-22 14:06:31] [ERROR] файл 'missing.txt' не знайдено
```

## Залежності

| Крейт | Призначення |
|---|---|
| `flate2` | Стиснення та розпакування Gzip/Deflate |
| `chrono` | Часові мітки в журналі |
